# Security

This integration handles Dreame account logins, so security problems matter. Please **don't open a public issue** for one.

Report it privately instead: go to the repository's **Security** tab and choose **Report a vulnerability**. You'll get a reply within a week.

Examples of what to report:

- Your email, password or tokens appearing in logs, diagnostics or anything sent somewhere other than Dreame.
- A way to make the integration send a purifier a command its profile doesn't allow.

Only the latest release gets fixes.
